PhotoCraft is an open source photo editor that runs in your browser, built with Rust and WebAssembly. Open an image from your device, edit it locally, then save or export it as a browser download.

Your documents are processed on your device and are not uploaded to the PhotoCraft server. The app keeps browser preferences in local storage; it does not provide server-side document storage or web autosave. Save your work before closing or reloading the page.

Use a modern browser with WebGPU or WebGL2 support. HTTPS enables WebGPU and clipboard features in supported browsers. The install downloads and verifies the official PhotoCraft v0.15.1 web release at first start.
