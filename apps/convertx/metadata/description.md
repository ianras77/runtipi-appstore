# ConvertX

ConvertX is a self-hosted online file converter with support for over a thousand formats, batch conversion, user accounts and conversion history. The application stores its database and conversion files under `/app/data`, which this Runtipi entry persists.

## First start

Open the private Runtipi HTTPS address and create the first account promptly. ConvertX permits the first account to be registered before an administrator exists; avoid leaving a fresh instance reachable by untrusted users during setup. Additional account registration and unauthenticated conversion are disabled by default. The JWT signing secret is generated by Runtipi. Temporary files are cleaned up every 24 hours by default, and concurrent conversions are limited to two to keep resource use bounded.

## Security note

Upstream ConvertX v0.19.0 has a reported local-file disclosure in its Pandoc reStructuredText conversion path (CVE-2026-108694 / GHSA-r4xg-82px-pwx6). This install is marked non-exposable and limits the service to its initial account. Keep it private and do not enable extra account registration or unauthenticated conversions. Review the upstream advisory and move to a release with a confirmed fix before enabling access for other users.

Keep the app's Runtipi configuration and persistent data together in backups. The container runs with UID and GID 1000 by default; change those fields only if your host's app data ownership requires different IDs.
