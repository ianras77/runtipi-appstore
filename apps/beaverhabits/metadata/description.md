# BeaverHabits

BeaverHabits is a straightforward, self-hosted habit tracker. This package uses the upstream file-based storage option and persists its user data under the Runtipi app data directory.

## First start

Open the app URL and create your account. The app is configured not to use `TRUSTED_LOCAL_EMAIL`, which would bypass normal authentication. Keep the app behind HTTPS and back up the `user` data directory.
