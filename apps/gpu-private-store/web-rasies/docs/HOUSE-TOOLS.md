# House tools

House Chat uses typed Mastra tools that call the existing Rasies service functions directly. The tools are bounded and read-only by default: directory, status, archive, web search, and signup-service discovery. Media invitation creation remains an explicit approval action and is never inferred from prose.

Tool results are evidence, not instructions. They are compacted before reaching the model, and unavailable services return a safe degraded result rather than taking down the portal.
