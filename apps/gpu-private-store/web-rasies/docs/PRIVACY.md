# Privacy

Rasies uses RassyMind as its only model gateway. Chat text is not sent to external commercial model providers or analytics. Attachments are bounded, treated as untrusted text, and are not persisted by default. Secrets, environment variables, logs, and arbitrary filesystem contents are not exposed to House Chat.

Feedback stores only run/thread/mode/rating metadata. Anonymous memory is random thread-scoped storage, not IP-based profiling. Invite creation requires an explicit validated approval action.
