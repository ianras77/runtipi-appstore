# RassyMind integration

The Mastra provider uses `RASSYMIND_BASE_URL`, `RASSYMIND_API_KEY`, and semantic aliases such as `rassy-fast`. Legacy `CAT_*` values are fallback-only compatibility inputs. Physical models and GPU assignments are never hardcoded here.

The live capability catalog and authenticated lane qualification remain deployment checks; this source package does not silently infer them.
