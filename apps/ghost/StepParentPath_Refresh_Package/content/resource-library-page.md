## Core message

Some readers need structure.
Some need comfort.
Some need one sentence that helps them step out of panic.

The library should organize support around those real needs:

- comfort notes for hard days
- longer articles for alignment, repair, and belonging
- practical scripts for common tense moments
- reminders that trust grows slowly and still counts
