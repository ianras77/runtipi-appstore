# The Stepparent Path Refresh Package

This package is designed to sit **alongside the current site**, not replace it.

It has two jobs:

1. Add a merged `edition` theme refresh that keeps the current site structure and existing content intact.
2. Provide additive copy modules for the pages and posts you already have, plus a few new trust-building pages.

## What is in here

- `theme/`
  - the merged `edition` theme copy
  - `routes.yaml` with the current routes plus new static support pages
- `content/`
  - additive modules for existing pages
  - new page drafts
  - launch post drafts
  - newsletter and editorial support

## What this package does not do

- it does not overwrite the database
- it does not delete current posts or pages
- it does not replace the current site architecture

The existing site stays intact. These updates are layered in around it.
