# Install Information

After Ghost is installed, head over to `https://yourdomain.com/ghost/` to finish setup and create the admin account.

## Included refresh packages

This app folder now includes:

- [StepParentPath_Refresh_Package](/srdata/runtipi/runtipi/runtipi-appstore/apps/ghost/StepParentPath_Refresh_Package)
- [StepParentPath_Merged_Theme](/srdata/runtipi/runtipi/runtipi-appstore/apps/ghost/StepParentPath_Merged_Theme)

These are built to work **alongside the current Stepparent Path content**, not replace it.

They contain:

- a merged `edition` theme refresh that keeps the current site structure
- additive homepage sections and new trust-focused static pages
- page modules, launch post drafts, and newsletter/editorial guidance

## What is preserved

- the existing Ghost database
- current posts and pages
- current routes and site structure, with only additive route entries for new support pages

## Suggested next steps

1. Keep the existing content volume intact.
2. Sync the merged theme into the active `edition` theme folder.
3. Upload or sync the updated `routes.yaml`.
4. Use the refresh package content modules to expand the live site without replacing current copy.

Ghost still provides the publishing engine, memberships, newsletters, and admin tooling; these packages add a stronger editorial and visual layer for The Stepparent Path while preserving what is already there.
