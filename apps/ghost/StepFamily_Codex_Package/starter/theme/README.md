# Stepfamily Circle Theme

This theme gives Ghost a calmer, trust-centered presentation for a step-parent community site.

## Before you activate it

1. Zip the contents of this theme folder and upload it in Ghost admin.
2. Upload `routes.yaml` in Ghost Labs so the custom routes work.
3. Set your site title, description, logo, and navigation in Ghost admin.

## Recommended post tags

- `#guide`
  - for longer framework pieces that should appear in `/guides/`
- `#comfort`
  - for shorter reassurance-driven posts that should appear in `/comfort-notes/`
- `feature-home`
  - optional visible tag if you want to flag posts you may want to feature elsewhere

## Suggested first publish sequence

1. Publish the About page copy from `starter/content/about-page.md`
2. Publish one comfort note
3. Publish one longer guide
4. Publish the newsletter welcome note
5. Publish the community promise page

## Tone check

If the site starts sounding combative, overly certain, or punitive toward children or former partners, the tone has drifted. Bring it back toward calm clarity, honest boundaries, and humane language.
