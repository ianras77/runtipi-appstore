# Step Family Codex Package

This package turns a fresh Ghost install into a warmer, more trustworthy starting point for a **step-parent community site**.

It is designed to make the site feel:

- calm instead of frantic
- practical instead of performative
- child-respecting instead of adversarial
- hopeful without becoming vague or sentimental

## What is in here

- `starter/theme/`
  - A custom Ghost theme scaffold with a polished homepage, support pathways, community pages, and a calmer visual system
- `starter/content/`
  - Ready-to-use page copy, launch post drafts, newsletter copy, and an editorial calendar for the first publishing stretch

## Core editorial direction

This starter is built around a few steady assumptions:

1. People come to a step-family site looking for relief, language, and next steps.
2. The house becomes safer when adults lower fear, reduce reactivity, and protect belonging.
3. Readers trust a site that refuses shaming, cheap certainty, and side-taking against children.
4. Community grows when people feel seen, not judged.

## Suggested setup flow

1. Upload the theme in `starter/theme/` as a Ghost theme ZIP.
2. Upload `starter/theme/routes.yaml` in Ghost Labs to enable the custom routes.
3. Set your site title, tagline, logo, and navigation in Ghost admin.
4. Paste in the draft copy from `starter/content/`.
5. Publish three to five comfort-first posts before promoting the site.

## Publishing rule that matters most

If a piece of writing makes the reader feel smaller, more afraid, or more hardened toward the children in the home, it should not go live. The site should help families return to steadiness, honesty, and wiser action.
