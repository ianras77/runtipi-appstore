# RapidForge

RapidForge is a self-hosted workspace for building webhooks, APIs, dynamic pages, and scheduled tasks with Bash and Lua scripts. Its SQLite database and application files persist under the Runtipi app data directory.

## First start

Open the app URL and sign in with the initial administrator credentials printed in the RapidForge container logs. RapidForge prints these credentials only on first startup; change the password after signing in and retain it securely.

Back up the app's `data` directory to preserve workflows and settings.
